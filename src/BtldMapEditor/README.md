# BtldMapEditor

编写 Lua 工具、接入格式研究或增加 XML 页面，先看 [Lua 开发手册](../../EditorLayout/脚本编写.md)。

战役地图编辑器。打开关卡按后缀识别，经 [`BtlCore`](../BtlCore/README.md) 转成内存 BtlFront 再编辑。

## 运行

仓库根打开 `BtldMapEditor.sln`，启动项目选 **BtldMapEditor**。输出：仓库根 `dist\`。

运行时的默认格式文件固定为程序旁的 `battle.fbs`（本仓库输出为 `dist/battle.fbs`），不再搜索工作区或当前目录，也没有内嵌回退。文件缺失会提示完整路径；替换后重启编辑器生效。构建时从 `schema/battle.fbs` 复制这个发布文件。Lua 研究扩展在字段校验前加载；目前部队四个字节仍用两个等宽 `ushort` 在内部兼容，导出的实际字节与新版 FBS 一致。

| 菜单 | 作用 |
|------|------|
| **新建关卡地图…** | 空白图 |
| **打开…** | `.btl` / `.json`（字段名或字段 ID） |
| **导出为…** | `.btl` / JSON 字段名 / JSON 原始字段 ID |
| **脚本工具** | Lua 声明自动生成的工具菜单；带参数的工具自动显示输入窗口 |

## 结构

| 路径 | 作用 |
|------|------|
| `Front/` | 会话、注册表、编辑器侧 Front JSON |
| 其余 `.cs` | 窗体 / 画布 / 贴图 |

依赖：同目录的 `BtlCore`（读写转换）。显示用名表和贴图来自仓库根 `GameData` / `地形贴图相关`（构建时拷到 `dist`）。

右侧面板的输入框和修改动作来自仓库根 `EditorLayout`。自己写 Lua 或加输入框，见 [`EditorLayout/脚本编写.md`](../../EditorLayout/脚本编写.md)。

## 注册表模式

打开 `.btl` 后，注册表默认显示**原始文件（只读）**。原始字节、文件路径和 SHA-256 保留在会话中，地图编辑和撤销不会替换它们。切换到注册表也不会隐式同步地图。列表分别标记已写出、未写出、类型未确定、解析失败、相对偏移为零、指向零填充和解码解释；选中字段可查看完整内容、原始字节、指针槽及诊断。

- **用 .fbs 重新解释**：从保留的原始字节生成一份新的查看树；不覆盖当前编辑文档，也不改变其它模块的 schema。未知字段保留字节间隔，失败字段保留实际槽。加载失败保留上一份有效视图。
- **仅导入名称与说明**：按字段路径叠加名称及注释；不改变查看树的类型和值。
- **仅原始槽**：不套用 schema，展示 Root 实际 vtable 槽和原始字节间隔；不猜测未知字段的类型。
- **恢复内置 schema**：恢复打开时使用的内置解释。
- **当前文档**：查看现有编辑数据，没有物理字节来源；默认只读。确认需要修改时勾选“允许编辑当前文档”。当前文档的大集合预览上限为 4096 项；原始文件的虚拟列表支持完整集合。

原始文件与当前文档是两个不同的对象；原始视图不会随地图修改更新。行为树的原始字节元素保留，附加 `decoded` 节点供 JSON 钻探。导入 JSON 或新建地图没有原始二进制，只能查看当前文档及导入名称。

读取出现错误、截断、类型猜测或无法解释的字段时，会话只允许查看，关闭地图修改及所有重建导出入口。更换查看 schema 不会自动解除这个限制或替换编辑文档。游戏原版中已有的零填充表指针按现有兼容约定处理，但在原始视图中单独标示，保留实际指针。

外部 schema 查看支持标量、字符串、表、向量、带自动对齐的嵌套 struct、整数 enum、普通数值／布尔／enum 缺省值和 `required` 指针字段。联合类型、定长数组、限定名 root_type 等尚不支持，会明确报错。查看有深度、向量长度和行为树解码预算，超过预算显示诊断；原始字节仍保留。未知槽的字节间隔可能包含填充，不声称是字段实际宽度。

注册表回归检查：`dotnet run --project tests/Registry.Smoke/Registry.Smoke.csproj -c Release`。追加 `-- --samples --render` 可只读检查本机原版样本并生成界面截图到 `artifacts/registry-smoke/`。

普通工具从 [Lua 开发手册的入门示例](../../EditorLayout/脚本编写.md#3-第一个可用工具) 开始。把 Lua 放在 `EditorLayout.user/tools`，重新加载布局即可使用；不需要 XML。默认菜单只提供「按地块顺序分配单位 UID」；原生命、经验、金币和地形工具移至 `EditorLayout/examples/常用工具.lua`，不自动加载。部队、势力、地图及图层用具名属性访问，打包字段由公共库处理。整批工具共用一个事务和一步撤销。编号范围与引用维护见 [单位 UID 工具](../../EditorLayout/单位UID工具.md)。

页面动作脚本也已改为对象调用，覆盖创建/删除、可选部队配置、建筑/工事、天气/目标/路线、行为树以及扩图。当前模块归属、公共扩展入口和迁移说明见 [Lua 对象扩展](../../EditorLayout/对象扩展.md)，验证方法见 [Lua 开发手册](../../EditorLayout/脚本编写.md#17-排错与验证)。

编辑页和新建地图对话框全部由 XML 动态生成，不再创建旧的硬编码属性面板。地形贴图选择和国家行为树使用 XML 声明的专用控件；势力、地图尺寸、战争迷雾和地图外部队也已经迁入 XML。新增页面只需在 `layout.xml` 注册，热加载失败保留上一份有效布局。

文档持有固定 schema，JSON 导出使用该解释，不再保存时重新查找另一份 `.fbs`。部队基础字段、行为/将领/特种配置及建筑/工事已采用公共字段目录，包含地图外部队表单和列表列。目录研究版本、依据和成功编辑所用字段随工作文档保存，使用方法见 [公共字段目录说明](../../EditorLayout/fields/README.md)。Lua/XML、画布动作、原生随机地形操作和注册表修改均通过 `Document.Editing` 提交，共用回滚和撤销历史。

地图从文档单向投影。保存 BTL、导出 JSON、工作文档快照和 JSON 查看均直接读取已提交文档，不再调用 `SyncGrid`，也不负责补交画布缓存。随机变种只改目标位段，随机偏移只改对应成员，不重建部队、事件或属性向量。`MapCell` 中的节点仍引用文档，消费方应只读；新增编辑入口必须在事务中修改文档，再重投影。旧 `FrontNav.SyncGrid` 与 `RecordExternalChange` 保留供兼容调用，当前编辑器已无调用点。

一次画笔拖动或地形偏移拖动通过公共历史分组合为一次撤销。每次移动立即提交；失败只回滚该次移动。鼠标释放、失去捕获、窗口失焦或撤销等中断会结束分组并停止落笔。注册表失败回滚或撤销替换树后，会刷新节点引用，后续编辑继续作用于当前文档。

Lua API 2 保留原有底层接口，增加固定参数的数据、JSON、剪贴板及会话状态接口。宿主执行预算和失败回滚、只读刷新缓存、64 位整数精确读写的边界见 [`BtlScriptHost/README.md`](../BtlScriptHost/README.md)。地形字段在一次刷新中共用属性扫描，读取不再生成整份关卡快照。

Windows UI 回归自检：先 `dotnet build tests/XmlUi.Smoke/XmlUi.Smoke.csproj -c Release -m:1`，再 `dotnet run --project tests/XmlUi.Smoke/XmlUi.Smoke.csproj -c Release --no-build`。可追加 `-- --render`，把页面预览写入 `artifacts/xml-ui/`。该自检覆盖页面挂载、样例加载、刷新不写入、热加载、复选框与工具撤销重做、自动参数窗口、部队顺序/重叠部队/额外地形属性保留、嵌套行为树编辑、地图外部队下标、路线字段和新建窗口默认值。`MapTransactionChecks` 另覆盖真实鼠标事件的历史分组与捕获丢失、拖动中撤销、原生批次及注册表回滚，以及过期画布不会污染各个导出入口。

## 地图平移与缩放

地图工具栏提供「显示地块ID」「显示地块坐标」「显示贴图偏移」三个独立开关，默认仅开启地块 ID。地块 ID 从 0 开始，等于 `y * 地图宽度 + x`，与部队 UID 分配工具使用的所在地块编号一致；简笔和贴图外观都可显示。ID 与坐标同时开启时合并为 `ID (X,Y)` 一行。切换只影响视图，不改文档或历史。

`EditorMapCanvas` 使用独立视图偏移和原生滚动条，不使用 `ScrollableControl` 搬移窗口旧像素。右键拖动只更新视图坐标并合并重绘；每次将完整双缓冲帧提交到窗口，露出的边缘先填背景，避免系统滚屏与局部自绘叠加造成拖影。原有 `AutoScrollPosition` 接口保留正值写入、负值读取的调用约定。

简笔模式保留两张视口大小的帧图，平移时复制重叠像素，只画新露出的条带；地图、选中格、预览格、图层、显示选项、缩放或尺寸改变会使对应缓存失效。缓存最多覆盖 600 万视口像素，两张帧图约 48 MB，不随整张地图面积增长；更大的视口直接绘制。字体复用，随画布释放。

大地图贴图仍使用带留边的视野缓存。采样网格和缓冲尺寸固定后，`TerrainSpriteRenderer.RenderRegion(..., reuseOverlap:true)` 可以保留重叠区，只重新渲染露出的条带。此选项只适用于同一份未修改的 `DecodedTerrainMap` 快照；实际地图修改会换快照，图层或采样步长改变也重新绘制。默认 `RenderRegion` 保持完整渲染语义。

滚轮缩放以鼠标为锚点：扣除固定画布留白，记录鼠标下的地图坐标，再计算缩放后的视图偏移。高分辨率滚轮累计不足一格的增量，多格滚动按格数处理。地图边界或地图比窗口更小时，偏移仍限制在可显示范围内。

导航回归运行：`dotnet run --project tests/XmlUi.Smoke -c Release -- --canvas-navigation-only --render`。使用本机 `dist/GameData` 和原版 `conquest1.btl`，检查连续平移耗时、鼠标锚点、命中格、滚动条、边界及窗口调整；导航不得修改文档和历史。增量贴图与完整渲染逐像素一致；简笔帧检查容许 GDI+ 浮点平移在抗锯齿边缘产生最多 2 级颜色舍入差，其中超过 1 级的像素占比不得高于万分之一。报告和预览保存到 `artifacts/canvas-navigation`。`Performance.Smoke --sprites --verify` 另验证海岸、气候、偏移、建筑工事、不同采样倍率及修改后的脏区渲染。
